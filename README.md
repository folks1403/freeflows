# Free Flows — teste iPhone

Repositório separado para a POC nativa iOS em SwiftUI. O backend e as chaves de IA ficam fora deste repositório.

- Projeto: `ios/FreeFlows.xcodeproj`
- Como compilar: [ios/COMPILAR.md](ios/COMPILAR.md)
- Recursos e limites: [ios/README.md](ios/README.md)

O GitHub Actions tenta compilar para aparelho real e gerar `FreeFlows-unsigned.ipa`. O arquivo ainda precisa ser assinado antes de instalar. Não coloque senha Apple, chave Gemini, certificados ou `.env` neste repositório.
